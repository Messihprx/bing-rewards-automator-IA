O **Bing Rewards Automator Pro** é uma ferramenta de automação inteligente desenvolvida para otimizar o ganho de pontos no Microsoft Rewards. Diferente de scripts simples, este projeto utiliza **Inteligência Artificial (LLMs)** para gerar termos de busca humanos e variados, evitando padrões repetitivos.


---

## ✨ Funcionalidades

* **🧠 IA Generativa (NVIDIA API):** Utiliza modelos como Llama 3.1 para criar buscas aleatórias e naturais.
* **📱 Modo Híbrido:** Suporte para buscas em **Desktop** e **Mobile** (iPhone Emulation).
* **⌨️ Digitação Humana:** Simula o ritmo de digitação letra por letra com intervalos aleatórios.
* **⏱️ Countdown Real-time:** Contagem regressiva visual na interface entre as pesquisas.
* **🛡️ Tecla de Emergência:** Atalho global (padrão `ESC`) para encerrar o processo instantaneamente.
* **💾 Persistência de Dados:** Salva automaticamente suas configurações de API e preferências.

---

## 🛠️ Pré-requisitos

1.  **Navegador:** Microsoft Edge instalado.
2.  **Conta:** Estar logado no seu perfil do Edge.
3.  **API Key:** Uma chave gratuita da [NVIDIA Build](https://build.nvidia.com/meta/llama-3_1-8b-instruct)

---

## 🚀 Como Usar

### Para Usuários (Executável)
1. Baixe a versão mais recente em Download abaixo.
2. Extraia o arquivo `.zip`.
3. Execute o `Bing_Rewards_Automator.exe`.
4. Configure sua API Key na aba **Configurações** e clique em Salvar.
